Keycloak SSO Demo - Realm Unificado

USE_CASE_1: SSO in corporate and citizen applications (same realm)

Realm Unificado - SSO Corporativo y Ciudadano Este demo muestra un realm único (unified-realm) que contiene tanto aplicaciones corporativas como de ciudadano. Un usuario puede tener roles tanto de empleado como de ciudadano en la misma sesión, permitiendo acceso a todas las aplicaciones con una sola autenticación.
⚠️ Riesgo de Seguridad Identificado Un empleado puede actuar también como ciudadano en la misma sesión. Las aplicaciones deben validar roles específicos para cada contexto y documentar los riesgos asociados.
Unified Realm (unified-realm)
Realm único que contiene aplicaciones corporativas y de ciudadano. Usuarios pueden tener múltiples roles: empleado, manager, admin, ciudadano
Portal de Empleados
http://localhost:3001/portal/
Requiere: empleado
Gestión de Proyectos
http://localhost:3001/proyectos/
Requiere: empleado
Panel de Administración
http://localhost:3001/admin/
Requiere: admin
Aplicación Cliente
http://localhost:3001/cliente/
Requiere: ciudadano

Usuarios de Prueba:

  • juan.empleado / empleado123 - Solo empleado
  • maria.gerente / gerente123 - Empleado + Manager
  • carlos.admin / admin123 - Empleado + Manager + Admin
  • pedro.ciudadano / ciudadano123 - Solo ciudadano
  • ana.empleado.ciudadano / empleado123 - Empleado + Ciudadano ⚠️
Características del SSO Unificado:
  • Una sola autenticación para todas las aplicaciones
  • Un usuario puede tener múltiples roles simultáneamente
  • SSO completo entre aplicaciones corporativas y de ciudadano
  • Tokens compartidos para todas las aplicaciones del realm
