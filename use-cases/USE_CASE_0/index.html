Keycloak SSO Demo

Portal de aplicaciones con Single Sign-On (SSO) usando Keycloak

Demostración de múltiples realms Este demo muestra cómo diferentes aplicaciones pueden usar realms completamente independientes en Keycloak. Cada realm tiene sus propios usuarios, roles y configuraciones.
Empresa Realm (empresa-realm)
Realm para aplicaciones internas de la empresa. Usuarios: empleados, gerentes y administradores.
Portal de Empleados
http://localhost:3000/portal
Gestión de Proyectos
http://localhost:3000/proyectos
Panel de Administración
http://localhost:3000/admin

Credenciales del Realm Empresa:

  • juan.empleado / empleado123
  • maria.gerente / gerente123
  • carlos.admin / admin123
Cliente Realm (cliente-realm)
Realm independiente para aplicaciones de clientes. Usuarios: clientes regulares, premium y VIP.
Aplicación Cliente
http://localhost:3000/cliente

Credenciales del Realm Cliente:

  • ana.cliente / cliente123
  • luis.premium / premium123
  • sofia.vip / vip123
Nota importante: Los usuarios de un realm NO pueden acceder a aplicaciones de otro realm. Por ejemplo, juan.empleado (empresa-realm) NO puede iniciar sesión en la aplicación cliente (cliente-realm), y viceversa. Cada realm es completamente independiente.
